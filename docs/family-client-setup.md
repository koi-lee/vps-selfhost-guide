# 在另一台电脑配置 Clash Verge Rev

本页只复用自己的 VPS 线路。为该使用者准备独立身份和私密配置，不需要购买其他 VPN。多人使用先由管理员按 [3X-UI 共享教程](3x-ui-family-sharing.md) 配置身份、HTTPS 订阅并完成撤销验收；不能将单密码 HY2 模板直接说成支持独立用户。

## 下载与备份

从 [Clash Verge Rev 官方发布页](https://github.com/clash-verge-rev/clash-verge-rev/releases) 下载对应系统和架构的稳定版，记录客户端与内核版本。下面的菜单名参考 macOS Clash Verge Rev v2.5.2，其他版本以实际界面为准。

更新已有配置前，在「设置」找到配置目录入口，关闭客户端后复制配置目录到带日期的新文件夹，再打开客户端。无法确定目录时，至少把目标配置的扩展脚本和扩展覆写完整另存备份；不要删除其他已有配置。

## 导入自建配置

1. 导入该使用者的私密 YAML；若已完成个人 HTTPS 订阅服务验收，也可导入其独立订阅。核对服务器、证书、节点身份及已启用线路，不能导入未替换的示例。
2. 在目标配置卡片的「扩展脚本」中填入 [shared-profile.js](../scripts/shared-profile.js)。需要简化面板时，将 [simplify-panel.js](../scripts/simplify-panel.js) 追加在末尾，保存为一份脚本。
3. 启用这张配置卡片，必要时重新激活；不要把脚本装到全局扩展脚本。
4. 在规则模式下，基础界面选「上网线路 → 自动切换（推荐）」；简化界面选「上网方式 → 自动上网（推荐）」。客户端可能保留旧选择，需核对实际选中项。
5. 手动测试每条已启用线路，操作入口见 [客户端说明](client-failover.md)，测试后恢复自动。

如果旧配置包含外部 `proxy-providers`，公开脚本会拒绝处理。请为自建线路使用独立配置，保留原配置及其备份，不直接覆盖私人扩展设置。

## DNS 与验收

如果启用了全局 DNS 覆写，参考 [国内 DNS 模板](../templates/domestic-dns.example.yaml) 合并设置，再查看运行时配置确认 direct-nameserver 和国内 nameserver-policy 生效。不要盲目覆盖整份 DNS 文件。

- 先验证系统代理，再单独验证需要使用的 TUN。
- 自动模式访问国内与海外站点；在连接页核对国内 DIRECT、海外当前自建线路。
- 手动选择各条已部署线路并发送新请求；切回自动后再次检查。
- 重启客户端后核对配置、模式及连接；已有连接不保证立即迁移。
- 旧 Timeout 与真实访问冲突时，重新检测并查看连接记录。

失败时恢复备份脚本和相关覆写并重新激活，不用重建账号、删除订阅或重装客户端。完成 [适用的验收项](verification.md) 并记录结果后，才能报告这台电脑配置完成。
