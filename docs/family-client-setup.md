# 媳妇儿电脑配置步骤

目标是让她的电脑也能使用同样的国内直连和日本低延迟自动选择，但不复制你的订阅凭据。

1. 安装 Clash Verge Rev，导入她本人有权使用的订阅链接。
2. 先只添加「旧」订阅，确认订阅列表能看到日本节点。
3. 在该订阅的扩展脚本中使用 `旧订阅-日本自动测速-20260920.js`，重新激活订阅。
4. 打开「代理」页，保持「规则」模式，确认出现「上网方式」和「日本上网（自动测速）」。默认应为日本自动测速。
5. 用一个国内网站和一个海外 HTTPS 地址各打开一次；国内连接应为 DIRECT，海外连接应显示日本测速组当前节点。

不要把你的订阅 URL、订阅缓存、profiles.yaml 或私有 Merge 文件发给她；这些文件可能包含凭据。她的电脑应单独保存自己的订阅和备份。后续若要加入 lizean，再为她单独配置 v16 面板脚本，不能直接覆盖旧订阅脚本。

验收范围：脚本离线回归通过，旧订阅实际 YAML 含 10 个日本节点，生成的 Mihomo 配置校验通过。当前尚未在第二台真实电脑上完成安装和网络验收。
