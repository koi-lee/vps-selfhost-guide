# 在另一台电脑更新 Clash Verge Rev

更新每张订阅卡片自己的扩展脚本，保留那台电脑已有的账号和订阅链接。以下菜单名在 macOS Clash Verge Rev v2.5.2 实际查看；其他版本可能略有区别。

## 备份

在「设置」找到配置目录入口，关闭客户端后复制整个配置目录到一个带日期的新文件夹，再打开客户端。无法确定目录时，至少先把目标订阅当前的扩展脚本和扩展覆写配置完整另存备份；不要删除原订阅。

## 多国订阅（例如新、旧）

1. 打开订阅页，右键「旧」卡片 →「扩展脚本」。
2. 全选编辑器旧内容，用 [subscription-japan-url-test.js](../scripts/subscription-japan-url-test.js) 完整替换，保存。
3. 对「新」卡片单独重复一次。它们是两份绑定，只更新其中一张不会影响另一张。
4. 点击目标订阅卡片启用，必要时点击顶部「重新激活订阅」。
5. 打开代理页，保持「规则」，确认「上网方式」选中「日本上网（自动测速）」。
6. 要换国家，先在下方「全部国家节点列表」选目标节点，再在上方点击「切换到手动节点」。回到日常使用时点回日本自动。

不要安装在底部「全局扩展脚本」，否则可能错误处理自有订阅。首次默认日本；客户端保存的手动/DIRECT 选择可能优先于脚本默认，需核对蓝色卡片。

## 自有四节点订阅

使用那台电脑本人的自有订阅，在该卡片「扩展脚本」中填写 [shared-profile.js](../scripts/shared-profile.js)，再把 [simplify-panel.js](../scripts/simplify-panel.js) 追加在其末尾，作为一份脚本保存。该通用脚本适用条件见 [部署指南](deployment.md)。

开启跨订阅备用还需在该卡片「扩展覆写配置」合并 [日本 provider 模板](../templates/japan-providers.example.yaml)，将占位地址换成本人有权使用的订阅地址。只安装脚本不会自动读取其他订阅卡片。不要覆盖已有无关覆写设置。

## DNS 与验证

如果启用了全局 DNS 覆写，参考 [国内 DNS 模板](../templates/domestic-dns.example.yaml) 合并设置，再查看运行时配置确认 direct-nameserver 和国内 nameserver-policy 生效。不要盲目覆盖整份 DNS 文件。

- 逐张切换订阅，确认代理页对应当前订阅。
- 自动模式打开国内与海外网站；在连接页确认国内为 DIRECT、海外是当前自动组。
- 手动选一个可用的其他国家节点，再启用手动方式；确认新连接使用该节点。
- 返回自动模式并重启客户端，再确认模式和节点；已有连接不保证立即迁移。
- 卡片旧 Timeout 与真实访问冲突时，重新测速并查看连接，勿只凭一个标签判断。

失败时恢复备份脚本和相关覆写并重新激活；不用重建账号、删除订阅或重装客户端。第二台电脑尚未实机验收，完成上述检查后才算更新完成。
