# VPS、Hysteria2 与 Clash Verge Rev 常见问题

## 这是免费代理订阅吗？

不是。本项目提供部署资料和模板，需要自己的服务器和认证信息，不提供公共节点。

## 如何选择便宜 VPS？

比较实际续费、退款、流量和 UDP/IPv6 支持，优先试用后测试晚高峰。便宜和地理位置接近都不保证线路快。具体价格按供应商当时官方条款核对。

## 为什么用 HY2 主线路、VLESS/CDN 备用？

不同传输路径用于故障回退。它们若共用一台 VPS，不具备服务器级容灾，也不一定绕开共同网络故障。

## 开启 Clash 会让国内网站变慢吗？

要看实际路由。国内请求误走海外时应修正具体规则；连接页显示 DIRECT 也不能证明上传过程全部直连。需要找出真正的慢请求。

## Agent 可以自动完成全部部署吗？

Agent 可以按这些文档执行你授权的步骤，但购买、账号权限和实际网络条件仍需要你提供。当前只完成了离线测试，不能据此判断任意服务器都已验收。

## IPv6 必须开启吗？

不是。只有服务器和本地网络均验证可用时才保留 IPv6 节点，初期只作为手动备用。

## 应该关闭证书验证来修复错误吗？

应修复证书、域名和 SNI，而非默认关闭验证。模板使用占位域名和凭据，不能原样连接。

## 如何给朋友使用？

每人生成独立身份和订阅，撤销时同时撤销服务端与订阅。也可分享本仓库，让朋友用自己的 VPS 部署；勿共享自己的私密运行配置。
