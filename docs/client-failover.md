# 自动选择、手动换节点与国内直连

先在「订阅」页选择配置，再在「代理」页保持「规则」模式。不同订阅的节点池彼此独立；切换订阅会切换整份配置。

## 选择脚本

| 订阅类型 | 扩展脚本 | 默认行为 |
| --- | --- | --- |
| 多国订阅 | [subscription-japan-url-test.js](../scripts/subscription-japan-url-test.js) | 只在当前订阅的日本节点中测速选择 |
| 本教程的自有四节点配置 | [shared-profile.js](../scripts/shared-profile.js)，可在末尾追加 [simplify-panel.js](../scripts/simplify-panel.js) | HY2 → CDN → IPv4 TLS，配置备用 provider 后再转日本 |

为每张订阅卡片分别绑定对应脚本。不要把四节点脚本用于包含多个 HY2 的多国订阅，也不要把本机文件名当成另一台电脑的脚本路径。

## 手动选择国家

1. 展开下方「全部国家节点列表」（自有四节点配置显示「全部节点列表」），选中目标节点。
2. 在上方「上网方式」点击「切换到手动节点」。
3. 确认上方当前方式已变成手动，下方当前节点是目标国家。
4. 恢复日常使用时，在上方点回「日本上网（自动测速）」或「自动上网（推荐）」。

只选下方节点不会自动改变上方模式。上方是启用开关，下方是候选列表，两者不是重复的列表。原生界面不支持通过配置脚本让同一卡片同时完成切换和弹出节点列表。客户端可能记住上次手动/DIRECT 选择，重新激活不保证强制回到默认；以当前蓝色卡片为准。

有效期和剩余流量提示项不进入手选列表。手动节点不可用时不会自动换国家，要改选可用节点或返回自动模式。

## 日本测速与跨订阅备用

日本组每 15 秒检测，5 秒超时，50ms 容差避免频繁切换；按健康状态和延迟选取，不承诺每一刻绝对最快。没有日本节点时，多国脚本保留原配置。

自有线路需要跨订阅备用时，将 [japan-providers.example.yaml](../templates/japan-providers.example.yaml) 填入该订阅的「扩展覆写配置」。仅保留本人有权使用的订阅，替换占位地址；首次下载必须成功，才有备用候选。模板使用 japan-primary / japan-secondary，与公开四节点脚本对应。此机制不会自动在界面上切换订阅卡片。

## 国内直连与 DNS

保持规则模式。国内域名库和补充规则命中后走 DIRECT，海外连接进入上网方式。自动和手动模式都适用；国内识别基于规则与访问目标，不是根据用户所在地。

如果客户端开启全局 DNS 覆写，脚本内 DNS 可能被覆盖。请按 [domestic-dns.example.yaml](../templates/domestic-dns.example.yaml) 合并国内直连 DNS，并查看最终运行配置确认生效；保留现有其他 DNS 设置。Clash 内核/TUN 本身故障或本地断网仍会影响国内访问。
