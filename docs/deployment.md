# 从选购到 Clash Verge Rev

本页是独立 Hysteria/Xray 路线。需要给家人朋友分配独立订阅、统一管理用量时，先走 [3X-UI 面板路线](3x-ui-family-sharing.md)，不要同时执行两条路线的服务安装步骤。VPS 选购与网络预检可共用。

## 第一次搭建，先从这里读

本页需要在电脑和服务器上配置软件，不是购买后直接导入的成品订阅。首次阅读先不用执行命令，也不用先购买。

1. 先在 [README 的起步任务说明](../README.md)了解如何让 AI 助手协助；如果使用 AI，把仓库地址和任务说明一起交给它，先核对条件。
2. 填写 [本地参数表](parameters.example.md)中的预算、城市与运营商、电脑系统、是否已有 VPS 和域名。不知道的技术字段先留空，后续逐项确认；不要为填表猜配置。
3. 再读第 1 节决定是否购买。已有服务器直接核对条件；开通后才进入第 2 节。具体安装材料按 [执行手册](rebuild-runbook.md)与当前官方文档核对，阶段完成情况按下表记录。

几个会用到的词：**本机**是你正在用的电脑；**VPS**是租用的远程服务器；**终端**是输入命令的应用；**SSH**是远程登录服务器的方式；**DNS**把域名指向服务器；**TLS 证书**用于验证连接的服务器身份并建立加密连接。客户端装在本机，服务端软件装在 VPS，不要把命令执行位置混在一起。

如果还分不清命令应该在哪里执行，先让助手解释当前步骤、预期结果和恢复方法，不要整页复制执行。遇到错误保留脱敏报错，解决当前步骤后再继续。

## 先明确完整目标

默认完成 HY2 主线路、VLESS/CDN 与 IPv4 VLESS 备用、客户端自动回退和国内直连。先让 HY2 单独成功，再逐条添加备用，有助于定位 DNS、证书、认证或客户端问题；不要在第一条线路成功后就结束完整部署。

按下表执行，下面的编号章节用于查具体配置。先填写 [参数表](parameters.example.md)，安装映射见 [执行手册](rebuild-runbook.md)，各阶段结果写入 [验收记录](verification.md)。

| 阶段 | 操作位置与材料 | 通过条件与后续 |
| --- | --- | --- |
| A. 预检 | 本机 SSH、VPS、供应商与 DNS 控制台；第 1–2 节 | SSH 与救援入口可用，版本、端口、域名、证书和备份已核对 |
| B. 主线路 | VPS 第 3 节；本机提前执行第 6 节的 HY2 阶段配置 | 客户端明确选中 HY2 并完成真实 HTTPS 请求；保存可用配置，继续 C |
| C. 备用线路 | VPS 与 DNS/CDN 控制台，第 4 节；本机逐条加入节点 | IPv4 VLESS、CDN 分别手动选中后通过真实请求；失败线路不进日常自动组，记录待修复项 |
| D. 完整客户端 | 本机第 6 节，启用 shared-profile.js；第 5 节按用户数和分发需求执行 | 自动顺序 HY2 → CDN → IPv4、国内 DIRECT 与海外代理均核验，继续 E |
| E. 故障与恢复 | 本机和 VPS，按 verification.md | 逐级回退、恢复、重启和证书续期相关检查有记录；缺项明确列出 |

IPv6、多用户、面板与远程订阅是选配项。不启用可记为“不适用”；默认三线路中的一条受阻，应记为“未完成”，不能算完整三线路通过。购买、登录验证、影响现有业务的故障演练按授权执行，其他已授权步骤连续推进。

## 1. 注册账号、选购与开通

### 先判断套餐是否适合，再注册

已有合适 VPS 的读者直接跳过选购。没有服务器时，先核对预算、首期与续费总价、地区、流量、IPv4、UDP 和维护要求；个人轻量使用可从 1 vCPU、1 GB 内存的 KVM VPS 级别比较。

决定比较 RackNerd 时，可以从[作者推广链接](https://my.racknerd.com/aff.php?aff=21220)进入查看当前套餐，确认合适后再注册并登录。注册不等于购买或开通服务器，也不保证获得额外折扣。官方常规套餐与活动套餐可能不同，价格与周期以实际结算为准。

*如果你通过这个链接购买，我可能会获得佣金，用来维护和更新这份教程。*

账号资料、密码和验证码由本人填写并保管；阅读并接受服务条款后再完成注册，不在公开仓库或聊天中粘贴凭据。

### 再选择套餐并确认购买


购买前先把仓库文件夹和 README 中的任务交给 Agent，填写参数表。Agent 先查候选供应商官方价格和条款，不固定推荐过时促销。优先核对是否提供测试方式、试用或退款条件，再按你的运营商评估地区；地理距离不等于网络质量。对比续费、退款、虚拟化类型、流量配额、IPv6、UDP 支持和使用条款。小规模个人使用可从 1 vCPU/1GB RAM 级别评估，面板资源需求以所选版本为准；无需为此购买大磁盘或多台服务器。

付款由你确认。[官方服务条款](https://www.racknerd.com/terms-of-service)不提供无条件退款保证；付款前确认具体套餐的退款限制，不假设购买后一定能退。开通后测试晚高峰、HTTPS 成功率、丢包和小文件下载；不达标先停止追加付费，按适用条款处理并评估其他线路。结果填写本地验收记录。

### 开通后再部署

确认服务状态为已开通，取得自己的服务器 IP、SSH 端口和登录方式，保存在个人密码管理器中。先验证 SSH 能登录，再开始下面的系统准备；不要把购买成功页面当成代理已部署成功。

## 2. 系统准备

选择组件支持的 Debian/Ubuntu 稳定版。检查 `uname -m`、系统版本、时间同步、可用内存、`ss -lntup` 和现有防火墙，记录 SSH 实际端口。更新系统安全补丁；保持 SSH 可恢复访问。

准备自己的入口与 CDN 子域名；入口域名 A/AAAA 必须对应可达地址，未验证 IPv6 不发布 AAAA。用受支持的 ACME 客户端签发有效证书，配置自动续期及服务重载。DNS-01 的 API token 仅授权所需区域。

放行实际 SSH 管理入口、HY2 UDP 443、VLESS TCP 443，以及 CDN 源站 TLS 8443（仅需要 CDN 时）。不要公开数据库、无 TLS 面板、Mihomo 控制接口。

## 3. HY2 主线路与用户

新建路线先使用 [Hysteria 官方服务端](https://v2.hysteria.network/docs/getting-started/Server/)，按 [恢复执行手册](rebuild-runbook.md) 的模板部署 UDP 443、自己的有效域名证书和认证配置。模板为单密码起步版；多人独立撤销需要按所用版本实现并测试多用户认证，不能共用密码后声称每人独立。

需要面板和多人管理时转到 [3X-UI 整合教程](3x-ui-family-sharing.md)。该路线按官方 v3.8.5 资料说明统一管理的入站、用户与订阅；已有独立服务不能自动接管，须按迁移步骤处理。不要通过修改数据库补功能。

## 4. VLESS 与 CDN 备用

使用 [Xray 官方发布](https://github.com/XTLS/Xray-core) 和 [VLESS 入站文档](https://xtls.github.io/config/inbounds/vless.html) 配置独立服务，避免面板重写其配置。

- TCP 443：VLESS + TLS，`decryption: none`，每人独立 UUID，Vision flow `xtls-rprx-vision`，证书与入口域名匹配。
- TCP 8443：VLESS + WebSocket + TLS，路径 `/vless-ws`，独立用户列表，WS 用户不要带 Vision flow。证书应覆盖 CDN 回源所用主机名。
- 出站使用正常直连出口；按官方配置文档生成配置文件，以安装版本的帮助信息确认配置检查命令，检查通过后启动 systemd 服务。
- IPv4 与 IPv6 客户端节点使用同一 TCP 443 服务和用户；IPv6 节点服务器填自己的 IPv6 地址，TLS servername 仍填入口证书域名。

CDN 使用受支持的 WebSocket/TLS 端口。以 Cloudflare 为例，使用自己的 `cdn.example.com` 橙云记录，Full (strict)，客户端和源站均用 8443；先核对 [代理端口](https://developers.cloudflare.com/fundamentals/reference/network-ports/) 与 [WebSocket 支持](https://developers.cloudflare.com/network/websockets/)。源站证书、SNI、Host 和 WS 路径必须一致。不要把 HY2 UDP 或 Vision TCP 当作普通 WebSocket 送入 CDN。这里固定使用 Full (strict) 和 TLS 加密回源，不使用 Flexible 或明文回源。

分别验证 IPv4、IPv6、CDN 真实代理 HTTPS；CDN 返回 400 只能说明入口有响应，不能代替 VLESS 认证验收。未通过验证的备用线路先不要启用。

## 5. 个人订阅

本页独立服务不由面板统一计费或停用。先使用自己的本地 YAML 配置；多人共享优先按 [面板教程](3x-ui-family-sharing.md) 统一管理，并完成迁移或新部署验收。将独立节点链接放进面板订阅，不代表它自动控制了这些服务的认证和流量。

保留独立服务时，必须另行实现每位用户的独立认证、配置分发和全线路撤销，不能把单密码 HY2 模板直接用于独立用户管理。也可以只交付本地 YAML（无需订阅服务器）。这时提供的是手动配置，不是自动订阅；需要远程更新时另行配置 HTTPS 私密分发，关闭目录列表，使用不可猜测 token，避免记录完整 URL。令牌持有者可取配置，撤销和轮换必须可执行。

## 6. Clash Verge Rev

在本机从 [Clash Verge Rev 官方 Releases](https://github.com/clash-verge-rev/clash-verge-rev/releases) 安装对应系统/架构的稳定版，记录客户端与 Mihomo 版本。VPS 上运行的是 Hysteria/Xray，不安装桌面客户端。

### 随部署阶段生成客户端配置

复制 `templates/clash.example.yaml` 为本地私密的 `clash.local.yaml` 后修改，保留公共示例不变。每阶段保存后，在本机客户端「订阅」页导入该本地配置并启用；已有同名配置时按实际界面更新，避免误启用旧副本：

1. **HY2 阶段**：只保留 `proxies` 中的 HY2 节点，在 `上网线路.proxies` 中只保留 `HY2-main` 和 `DIRECT`；填写自己的服务器、密码与 SNI，选择 HY2 完成首次请求。此阶段可以先不加扩展脚本。
2. **备用阶段**：在已通过配置的副本中逐条加入 IPv4 VLESS 和 CDN 节点，同时将名称加入手选组，分别实测。IPv6 只有两端可用时才加入；未启用节点连同组内引用一起删除，不留下示例地址或占位凭据。
3. **完整阶段**：合并已验证节点，再添加下述扩展脚本并检查自动组。脚本支持阶段性只有一个节点的配置，但单节点不构成故障回退；默认三线路未齐时仍须报告缺项。

已有本方案自建服务生成的个人订阅也可以导入，但先核对节点角色、数量与身份；这里不指另购 VPN 订阅。生成后的配置使用与本机环境相符的 Mihomo 配置检查方式验证，检查通过再激活；不要打印完整配置或认证字段。

### 应用脚本并核对实际界面

将 `scripts/shared-profile.js` 完整粘贴到该配置的扩展脚本编辑器，全选覆盖旧内容后保存，重新应用该配置。不同版本按钮名称可能不同，以实际 UI 为准：更新订阅是重新拉取数据，使用/激活是应用配置；两者不要混淆。

规则模式下应显示“上网线路”，第一项“自动切换（推荐）”，内部 fallback 可见，完整三线路顺序 HY2 → CDN → IPv4；IPv6 只供手动选择；DIRECT 放最后。先开启系统代理验证浏览器，再按需求单独验证 TUN，避免其他 VPN 冲突。

脚本只支持这套模板的四种节点角色和基础规则，不用于覆盖复杂机场分组。输入各角色最多一个节点，名称唯一；IPv6 节点使用 IPv6 字面地址。脚本保留原认证、证书和带宽字段，不修改服务端。

国内显式域名、GEOSITE,cn 与 GEOIP,CN 走 DIRECT；脚本另将 cloudflare.com、cloudflare-dns.com 及其子域名列为 DIRECT 例外，不代表所有 Cloudflare 托管网站直连。其余走上网线路。GeoSite 和 GeoIP 数据必须可用且更新；异常时检查实际连接规则，不凭域名归属想当然补规则。

可选的 `simplify-panel.js` 会将入口改为“上网方式”，推荐项改为“自动上网（推荐）”；手动操作见 [客户端说明](client-failover.md)。只有追加该脚本后，才使用简化面板对应的操作步骤。

## 7. 性能与日常维护

自建线路使用优先级回退：HY2 仍通过健康检测但速度下降时，不保证切换。当前方案不使用最低延迟自动选择；不要擅自改变既有回退策略。保留 HY2 优先只是起点；用多个晚高峰样本决定顺序。检测小 HTTPS 204 不能衡量视频吞吐，测速结果应区分成功率、成功样本 P50/P95 和超时。IPv6 是否加入自动组必须单独长期验证。

不把别人的带宽参数、自签证书例外、运营商故障、控制 socket 路径照搬到新设备。自动回退只选后续连接的可用节点；已有失败请求可能仍需应用重试。

每一步按 [验收与恢复](verification.md) 留结果，再决定是否继续。

配置字段参考：[Mihomo HY2](https://wiki.metacubex.one/config/proxies/hysteria2/)。分享的脚本不设置 HY2 up/down；需要调节时按你的实际带宽核验。

## 8. 海外故障与国内访问独立

自动检测间隔为 15 秒，超时 5 秒，不能承诺在 15 秒内恢复。按 [自建线路回退与直连 DNS](client-failover.md) 核验 HY2 → CDN → IPv4；无需另购 VPN 订阅。Clash Verge 全局 DNS 覆写可能覆盖脚本设置，须核对最终运行配置。
