# 验收与恢复

## 离线测试（当前已验证的范围）

运行 `node tests/profile.test.js`，检查角色识别、重复执行、隐藏组、规则完整性、认证字段保留和不关闭证书验证。模板只是占位配置，不能直接使用。

## 使用者必须实际完成

- 记录系统、面板、HY2/Xray、Clash/Mihomo 的准确版本。
- 服务端配置检查通过；监听端口与计划一致；面板不暴露到公网。
- 每条声称可用的节点，对至少两个 HTTPS 目标各测 5 次；记录失败，不隐藏超时。手动切换完成后恢复自动。
- 通过浏览器访问国内和海外站点，在连接页确认对应 DIRECT/自动组；真实小文件上传与下载均成功。
- 经使用者确认后临时使主线路不可用，观察新连接是否切到 CDN，再恢复主线路；不能只看组名宣称自动回退验证通过。
- 重启客户端后规则、订阅与节点选择仍正确；重启 VPS 后服务自动启动。
- 第二个独立用户能连接；撤销测试用户后确实不能继续新建连接。
- 证书续期机制已检查，续期后能重载服务。
- 保存本地 `验收结果.local.md`，未验证项标为未完成；不要随公共包转发真实地址、截图、订阅和日志。

## 恢复

每次改动前分别备份服务配置、面板数据、unit、防火墙、客户端订阅和扩展脚本；私密备份不在分享包内。验证备份可读并记录恢复路径。配置检查失败不重载；连接失败时恢复上一个可用阶段，先保证 SSH 与主线路。

不要在故障时清空所有连接、重装系统或直接覆盖数据库。按 DNS → TCP/UDP → TLS → 认证 → 路由逐层排查。
