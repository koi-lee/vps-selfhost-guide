# 隔离验证记录

本轮仅本机静态配置和假数据测试，无网络监听、无系统代理/TUN/DNS 修改、无 VPS 连接、无生产配置加载。

通过：客户端组角色/顺序/幂等/认证保留；域名正则正反样本；保留名称拒绝；30 秒与 5 秒检测参数；文档链接；一次性测试密钥加密恢复、错误密钥、损坏密文、危险路径、拒绝覆盖。

发现并修复：分享脚本的 upos 域名规则多重转义导致合法域名无法匹配。新增 routing.test.js 先复现失败，再修复并复验。只修改分享仓库，未修改用户现用客户端。

命令：node --test tests/*.test.js；python3 tests/check_docs.py。备份假数据测试入口位于本地备份工具目录 test_backup.py。

未验证：Linux systemd 启动、Xray/Hysteria 真实协议握手、续期、多用户订阅、真实故障回退。没有启动 Docker 或安装内核；本次不能称为新 VPS 端到端演练。后续需独立虚拟机/测试 VPS，不能使用现有代理服务承担测试。
